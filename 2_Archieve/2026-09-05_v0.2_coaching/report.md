## 1. 코치 능력치가 작동하는 자리

| 능력치 | 작동 |
|---|---|
| 진단 | 능력치 관측 노이즈 σ = 25×(1−진단/100). 낮으면 엉뚱한 문제를 1순위로 꼽음 |
| 지도 | 담당 분야 훈련 이득 배율 0.6~1.4 (담당 코치 없으면 0.5) |
| 부하 관리 | 선수 주간 수용량 추정 오차 최대 35% + 과부하 편향 최대 10% |
| 소통 | 선수 이행률 0.7~1.0 (선수 멘탈과 평균) |
| 관찰 | 은닉 자질 추정 구간이 주당 최대 8% 좁아짐 |
| 성향 | 특정 능력치를 문제로 과대·과소 진단 (예: 구속 지상주의 감독 = 하체 파워 +50%) |

## 2. 30주 비교 (유망주 22세, quality 0.6, seed 3)

| 지표 | 우수 스태프 (5명) | 부실 스태프 (3명, 멘탈·의무 없음) |
|---|---|---|
| 파생 구속 | 82.2 → 83.7 mph | 81.8 → 83.3 mph |
| 파생 회전수 | 1949 → 2095 rpm | 1937 → 2058 rpm |
| 제구 σ | 0.278 → 0.274 m | 0.291 → 0.275 m |
| 감독 1순위 진단 적중 | 70% | 50% |
| 평균 과부하 (부하−수용량) | 0.05 | 0.82 |
| 부상 | 1회 | 0회 |
| 최종 능력치 | 하체 72·코어 75·손목 71·악력 68·반복 59·그립 68·체력 54·집중 71·멘탈 72·배짱 66 | 하체 64·코어 75·손목 67·악력 63·반복 59·그립 64·체력 51·집중 60·멘탈 64·배짱 58 |

읽는 법: 부실 스태프는 수용량을 1.8배 넘겨 계획해도 피로 페널티로 이득이 깎여 우수 스태프를 따라오지 못합니다. 정신 능력치 차이(집중 71 vs 60)는 멘탈 코치 유무에서 옵니다. 부상 1회는 우수 쪽에서 났는데, 어깨 가동범위 훈련의 고유 위험이 원인이며 부실 쪽은 의무 코치가 없어 그 훈련 자체를 하지 않습니다.

## 3. 보정 이력 (이번 세션)
- 부상 확률을 세션 수가 아니라 과부하·피로² 기반으로 변경(초판은 우수 스태프가 부상 3회로 역전).
- 22세 나이 곡선 완화(0.85→0.92 시작)와 구속 사슬 감도 상향(0.14→0.20)으로 유망주 구속 79→82 mph 시작.
- 피로 누적을 (부하/수용량)²로 바꿔 과훈련이 이득으로 이어지지 않게 함.
