# v1.9 장면 전환 (2026-09-06)

방금 지시: 타격이 나오면 수비 장면만 보이는 창으로 넘어갔다가 끝나면 투구·타격으로 복귀. 이닝 교체마다 점수·통계 창으로 넘어가고 클릭으로 진행. 메모리 구성을 영리하게.

## 결론
- 장면 3개(투구·타격 / 수비 / 점수·기록)로 나눴습니다. 타구가 나오면 접촉 0.35 s 뒤 수비 장면(큰 중계 캔버스와 필드 미니맵)으로 넘어가고, 플레이가 끝나면 투구·타격으로 돌아옵니다. 3아웃마다 점수·기록 장면이 뜨고 "다음 이닝 진행"을 누르면 이어집니다.
- 보이는 장면의 캔버스만 그립니다(투구·타격 5개, 수비 2개, 점수·기록 0개). 숨은 캔버스는 그리지 않습니다.
- 점수·기록 장면: 라인 스코어(R/H/E), 양 팀 타자 기록(타석·안타·볼넷·삼진), 투수 기록(이닝·투구·피안타·실점·삼진·볼넷·평균 구속).
