# v2.6.1 테스트 유저 6명 플레이테스트와 반영 (2026-09-07)

방금 지시: 이것저것 테스트할 수 있는 유저를 호출해 게임 기능뿐 아니라 재미도 테스트.

## 결론
- 테스터 6명(캐주얼 모바일·KBO 골수팬·시뮬 고수·경기 관전자·QA 파괴·야구 초보)이 새로 만든 하네스 `tools/playtest.py`로 앱을 직접 조작했습니다. 시나리오 90여 편, 실행 200회 이상, 캡처 300장 이상이 `examples/out/playtest/`에 있습니다.
- 점수는 재미 5, 몰입 5, 깊이 3, 관전 5, 이해 4, 안정성 4로 낮게 나왔습니다. 공통 진단은 "틀은 갖췄는데 연결이 없다"였습니다. 규칙·데이터·화면은 KBO답게 짜였지만, 관리의 결정이 경기 결과로 이어지지 않고 폰에서는 조작이 막혔습니다.
- 지적 70여 건 가운데 40건을 이번에 고쳤습니다. 남은 것은 구조 변경이 필요한 3건(관리 층과 물리 엔진 연결, 폰 3열 레이아웃 재설계, 실명 앵커 보정)이며 다음 버전 과제로 남깁니다.

## 3. 남긴 것 (다음 버전)
1. 관리 층과 물리 엔진 연결: 구단 선수의 능력치로 타자·투수 프로필을 만들어 실제 투구에 반영해야 훈련·트레이드·피로가 의미를 가집니다. 지금은 물리 경기가 원형 12타자×5투수 위에 이름만 덧씌운 구조입니다.
2. 폰 3열 화면 재설계: 선수단·예산·이적을 탭으로 나누거나 행 버튼을 왼쪽에 고정해야 폰에서 조작할 수 있습니다.
3. 실명 앵커 보정: 구단당 상위 10~15명의 나이·투타·포지션·연봉을 수동으로 맞춰야 팬이 보는 어색함(1군 주전이 2군, 최정 25세)이 사라집니다.
