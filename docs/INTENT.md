# 배터리 의도 층: 투수와 포수가 따로 생각한다 (bbsim v0.3.0, 2026-09-05)

## 결론
투수와 포수는 같은 후보(구종 × 코스 11개)를 각자 다른 정보와 가중치로 채점합니다. 포수는 투수의 의도를 받아 60%의 무게로 포함합니다. 거기에 포수만 보는 것을 더합니다: 주자·아웃·점수·심판·시퀀싱·야수 배치·정확한 스카우팅·오늘 통하는 구종. 두 판단이 다르면 사인/흔들기(shake-off) 프로토콜로 조정하며, 기록에는 투수 의도·포수 사인·최종 선택과 각자의 이유가 모두 남습니다.

코드: `bbsim/agents/intent.py`(공통 채점), `pitcher.py`(투수 의도), `catcher.py`(포수 사인), `engine/plate_appearance.py::reconcile`(조정).

## 1. 투수가 보는 것 (`HeuristicPitcher.intent`)
| 입력 | 사용 |
|---|---|
| 카운트 | 공통 사전 가중치(볼 앞서면 패스트볼, 스트라이크 앞서면 변화구, 3볼은 존 안) |
| 오늘의 감 (feel) | 경기 시작 시 구종별 N(0, 0.12) 샘플, 결과마다 ±0.02 이동. 점수 +2×feel, 감이 나쁘면 코너 대신 존 안 |
| 피로 | 투구 수 60 초과분에 비례. 0.7 이상이면 패스트볼 의존 회피 |
| 자기 기억 | 이 타자에게 던진 직전 2구. 같은 구종 3연속 −0.9 |
| 스카우팅(흐림) | 타자 습관 사본, 정확도 0.6(σ 0.12로 흐림, 강타 존 40% 오독) |
| 공격성 | 존 안/추격 코스 선호 |
| 몸 | 사슬 구속 배율, 균형 σ 배율, 릴리스·회전축(intent가 아니라 spec_for에서) |

출력: PitchIntent(구종, 코스, 목표, 힘, 점수, 이유 목록, 상위 6개 순위).

## 2. 포수가 보는 것 (`HeuristicCatcher.sign`)
| 입력 | 사용 |
|---|---|
| 투수 의도 | 순위 점수를 0.6 배로 가산("투수 의도 반영") |
| 오늘 통하는 구종 | 결과 누적(헛스윙 +0.25, 볼 −0.12) × (0.8 + 0.8×레버리지) |
| 3루 주자·2아웃 미만 | 원바운드 위험(커브 0.30, 스플리터 0.35 …) × 3 감점, 낮은 추격 코스 2배 |
| 1루 주자 도루 위협 | 패스트볼 +0.4, 커브·스플리터 −0.4 |
| 심판 | 낮은 존 후하면 낮은 코스 +1.5·읽기, 높은 코스 −0.5 |
| 시퀀싱 | 터널 쌍(FF↔CH, FF↔SL, SI↔CH, CT↔SL …) +0.5, 헛스윙 유도 구종 반복 +0.3 |
| 야수 시프트 | 당겨치기 시프트면 몸쪽 +0.3 |
| 스카우팅(정확) | 정확도 0.85 사본, 가중치 1.0 |
| 레버리지 | 늦고 접전이면 2스트라이크 변화구 +0.3 |

출력: CatcherSign(구종, 코스, 점수, 이유, 순위).

## 3. 조정 (`reconcile`)
1. 투수 의도 → 포수 사인(의도 포함) 순으로 계산.
2. 사인 구종이 의도와 같으면 수락. 다르면 수락 확률 = 신뢰(0.75) × exp(−점수 차/0.6). 그 구종의 감이 나쁘면 절반.
3. 거부 시 포수는 그 구종을 제외하고 다시 사인. 최대 2회. 그래도 거부하면 투수 자기 선택.
4. PitchCall에 pitcher_choice·catcher_choice·shake_offs·agreed·이유가 남습니다.

300타석(프로필 B) 실측: 의도=사인 일치 약 60%, 흔들기 약 0.8회/타석.

## 4. 정보 경계
- 투수·포수 모두 타자 내부 상태(recognition·discipline 값)는 못 보고 `BatterTendencies`(공개 성향)만 각자 정확도로 흐려서 받습니다.
- 타자는 구종·회전을 못 보지만 릴리스 포인트는 봅니다. 같은 투수의 릴리스 평균과 6 cm 이상 다르면 release_read 확률로 "팁"을 얻어 인식이 +0.25 오릅니다(터널 깨짐).
- 심판 성향은 포수만 읽습니다(`GameContext.umpire_low_shift`).

## 5. 후속
- 포수의 투수 모델을 결과 누적에서 "구종별 기대 가치(run value)"로 확장.
- 타자 쪽 의도(노림수: 구종·코스 예측)를 같은 방식으로 추가해 배터리와 대칭 구조로.
- 감독·벤치의 개입(고의사구·수비 시프트 지시)은 게임 층에서.
