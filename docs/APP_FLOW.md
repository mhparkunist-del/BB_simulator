# 모바일 앱 인터페이스 계획 (2026-09-06, v2.2)

## 결론
가로 한 화면 웹앱을 기준으로 게임 흐름을 정했습니다. 타이틀 → 구단 선택 → 부임 인사 → 튜토리얼(처음만) → 정비(일정·훈련·선수단·기록) ↔ 경기(잠금) → 경기 종료 이벤트 → 정비. v2.2에서 이 흐름과 저장·불러오기, 훈련 위임, 포지션, 주루 판단, 경기 잠금까지 구현했습니다. 개별 투구 폼 훈련은 엔진이 브라우저에서 돌 때 물리에 연결됩니다.

## 1. 화면 흐름
| 단계 | 화면 | 내용 | 상태 |
|---|---|---|---|
| 1 | 타이틀 | 계속하기(자동 저장이 있으면), 새로 시작, 불러오기(슬롯 3) | 구현 |
| 2 | 구단 선택 | 6구단 카드(이름·상징색·모토). 선수단은 시즌 시작 시점의 같은 구단이고 이름·색만 바뀜 | 구현(선수단 차이는 다음 단계) |
| 3 | 이벤트 | 구단주 인사(부임 환영), 경기 종료 결과, 저장 완료 등 모달 | 구현 |
| 4 | 튜토리얼 | 처음 부임 때만 3단계(선수단 둘러보기 → 훈련 맡기기 → 일정 진행). 건너뛰기 가능 | 구현 |
| 5 | 정비 | 일정(다음 날 · 경기 날은 경기 화면으로), 훈련(방침 위임 또는 직접), 선수단(타순·로테이션·포지션·1군/2군·FA·카드), 기록, 예산·이적 | 구현 |
| 6 | 경기 | 경기 날에 경기 버튼 → 선발·타순 확인 → 플레이 볼. 시작하면 끝날 때까지 다른 화면으로 못 나감(내비 잠금, 저장·타이틀 비활성). 끝나면 결과 이벤트 뒤 정비로 복귀. 일정·기록에 반영 | 구현 |
| 7 | 저장 | 헤더 저장 버튼 → 슬롯 3개. 자동 저장은 1분마다와 경기 종료 때 | 구현 |

- 경기 날 규칙(v2.6): 경기 날은 넘길 수 없습니다. 일정 화면의 버튼이 "오늘 경기 시작"으로 바뀌어 경기 화면으로 보냅니다. 경기 화면에서는 한 구·타석·이닝 단위로 지휘하거나, "결과 바로보기"로 남은 경기를 애니메이션 없이 끝까지 진행해 결과 화면(점수·기록)을 봅니다. 결과 바로보기 중 "정지"를 누르면 그 자리부터 다시 지휘합니다. 경기 결과는 "정비로 돌아가기"를 누를 때 시즌에 반영됩니다.

- 장면 연출(v2.6): 플레이 볼을 누르면 수비진이 더그아웃에서 자리로 뛰어나가고 선발이 마운드로 걸어 올라갑니다(자막: 선발 등판·이름·구단). 이닝이 바뀔 때 수비하던 쪽이 더그아웃으로 들어가고 다음 수비진이 나옵니다. 경기가 끝나면 이긴 쪽이 마운드 근처에 모여 뛰며 팔을 들고, 진 쪽은 고개를 숙이고 더그아웃으로 걸어갑니다(자막: 승리!/패배·점수). 화면을 누르면 건너뜁니다. 결과 바로보기 중에는 등판·이닝 장면을 생략하고 종료 장면만 보입니다. 코드는 `js/render/cutscene.js`이고 인체는 기존 달리기·서기 자세 빌더를 재사용합니다.

## 2. 훈련
- 방침 위임: 직접 / 균형 / 타격 강화 / 투수 강화 / 유망주 육성 / 회복 우선. 직접이 아니면 매주 월요일에 방침대로 프로그램을 다시 배정하고, 피로 60 % 초과는 휴식으로 돌립니다.
- 개별 훈련: 선수 카드에서 프로그램을 고릅니다. 투수는 팔 각도·스트라이드·상체 기울기 슬라이더가 있고 값은 저장됩니다. 지금은 투구 은행이 미리 계산되어 있어 물리에 반영되지 않고, 엔진을 브라우저로 옮기면 pitching_params의 abd·stride·lean에 연결합니다.

## 3. 선수 데이터
- 포지션: 야수 C/1B/2B/3B/SS/LF/CF/RF/DH/OF/IF, 투수 SP/RP/CL. 선수단 목록의 셀렉트로 바꿉니다. 타순에 주요 포지션 8개가 비거나 겹치면 경고와 함께 빠른 시뮬 수비 강도가 자리마다 5 % 깎입니다.
- 타구 판단(run_iq): 주루 능력치. 안타 뒤 다음 베이스를 노릴지 송구 시간을 읽는 정확도(σ = 0.08 + 0.55·(1−판단))이고 과감성이 밀어붙입니다. 잘못 읽으면 2루·3루 주루사(single_out·double_out)가 납니다. 등급 "판단"으로 표시됩니다.
- 실명 선수단(v2.3): `tools/build_kbo.py`가 두 출처를 합쳐 `web/app/data/kbo.json`을 만듭니다. 위키백과 구단 명단 틀(틀:<구단> 명단)에서 전 선수의 이름·등번호·묶음(투수/포수/내야수/외야수)을 가져옵니다. KBO 공식 등록명단(Register.aspx, 팀별 postback)에서는 1군 선수의 투타·생년월일·신체를 가져옵니다. 등록명단에 없는 선수는 2군으로 두고 투타·나이를 이름 해시 시드로 채우며 `est: true`로 표시합니다. 2026-09-06 기준 10구단 944명이고 1군은 구단마다 24~34명입니다.
- 능력치: 실제 기록을 쓰지 않습니다. `club.js kboPlayer`가 구단·이름 해시로 시드를 만들어 능력치·잠재력·성격·계약을 뽑습니다. 같은 선수는 언제나 같은 값이고, 게임 안 추정값임을 부임 이벤트에서 밝힙니다.
- 물리 은행 연결: 실명 타자는 좌우 손에 따라 물리 타자 원형(좌 2종, 우 10종)에, 선발 5명은 투수 원형 0~4에 배정됩니다. 경기 화면은 원형 위에 이름·등번호·포지션만 덧씌웁니다(applyNames). 상대 구단도 같은 방식이고, 상대 타자는 일정에 잡힌 실제 구단의 1군 타자입니다.
- 선발 9명: 1군 야수에서 C·SS·2B·CF·3B·1B·LF·RF 순으로 포지션별 최상위 한 명을 고르고, 9번은 남은 최상위를 DH로 둡니다. 벤치는 12명까지입니다.
- 경기 화면 정보: 경기 준비 투수 카드는 체력 바(100·(1−피로) %)와 컨디션을 보여줍니다. 점수 버그는 대기 타자 2명을 보여줍니다. 이닝 교체 화면은 다음 타순 3명(타순·이름·좌우·포지션)을 KBO 중계 자막처럼 보여줍니다.
- 이름 사용 주의: 구단명·선수명은 공개 명단의 사실 정보이고 취미 프로젝트 안에서만 씁니다. 배포·판매 때는 KBO·구단의 상표·초상 허락이 필요합니다.

## 5. 화면 디자인 (v2.4)
- 글꼴: 숫자·로고는 Black Han Sans, 버튼·라벨·소제목은 Jua, 본문·표는 Gothic A1, 시각은 IBM Plex Mono입니다. 모두 Google Fonts이고 폴백은 시스템 글꼴입니다.
- 색(v2.5): 화면 전체가 구단 색을 따릅니다. `APP.theme(primary, accent)`가 구단의 주색·강조색에서 토큰(--team, --bulb, --go, --stripe 등)을 만듭니다. 배경 글로우·패널 틴트·버튼·점수 버그 띠·로고·램프가 그 토큰을 씁니다. 강조색이 어두우면 밝혀서 쓰고, 주색이 너무 어두우면(두산·롯데·KT) 진행 버튼은 강조색을 씁니다. 구단 선택 화면에서 카드를 누르면 바로 미리 보이고, 타이틀은 KBO 리그 남색·빨강입니다. 10구단 주색·강조색은 `web/app/data/kbo.json`(`color`, `color2`)에 있습니다.
- 배경: 위쪽 강조색 글로우, 좌우 아래 구단 주색 글로우, 사선 결, 주색 틴트 그라데이션을 겹쳤습니다. 패널은 유리 느낌(반투명 + 위쪽 하이라이트 + 그림자), 버튼은 둥근 입체(아래 그림자, 누르면 내려감), 램프·베이스는 켜지면 빛납니다. 경기 화면은 가장자리 비네트를 덧씌우고 점수 버그에 노란 세로 띠를 둡니다.
- 토큰은 `web/app/css/app.css` 맨 위 `:root`에 있습니다. 움직임 축소 설정(prefers-reduced-motion)에서는 전환을 끕니다.

## 6. 버튼 반응 (v2.6)
- 누르면 살짝 눌리고(아래로 2 px, 96 %) 떼면 튕겨 올라옵니다(104 %까지 넘쳤다가 제자리, 0.34 s). 누른 지점에서 물결(ripple)이 퍼지고, 터치 기기에서는 6 ms 진동을 줍니다. 구단 카드·선수 카드도 눌리는 느낌을 줍니다. 움직임 축소 설정에서는 모두 끕니다.
- 참고한 사례: [Hover.css](https://github.com/IanLunn/Hover)의 push·pop 효과, [Material Components ripple](https://github.com/material-components/material-components-web/tree/master/packages/mdc-ripple), [CSS ripple 정리](https://freefrontend.com/css-ripple-effects/). 라이브러리는 넣지 않고 CSS 한 블록과 위임 이벤트 두 개로 구현했습니다.

## 7. 플레이테스트 반영 (v2.6.1)
- 경기 날은 9이닝이고 시드는 경기마다 자동으로 바뀝니다. 연습 경기(경기 없는 날)는 3이닝이 기본입니다.
- 홈 경기면 우리가 말에 공격합니다. 점수판도 원정 팀이 위에 옵니다.
- 투수는 투구 수(체력 등급 S 110 ~ D 70구)나 한 투수 6실점에서 교체됩니다. 교체 투수 이름은 구단 불펜에서 옵니다.
- 헤더에 "도움말" 버튼이 있습니다. 타순·로테이션·초말·볼·스트라이크·등급·컨디션·사인·R/H/E·샐러리캡·트레이드·정비·결과 바로보기를 한 줄씩 설명합니다.
- 테스트 도구와 테스터 보고는 `docs/PLAYTEST.md`, `3_recent_report/2026-09-07_v2.6.1_playtest/`에 있습니다.
