# 코칭 스태프 시스템 (bbsim.game, v0.2.0, 2026-09-05)

## 결론
코치는 "불완전하게 보는 에이전트"입니다. 선수의 능력치를 자기 진단 능력만큼의 노이즈로 관측해 문제를 꼽고, 선수의 주간 훈련 수용량을 부하 관리 능력만큼의 오차로 추정해 훈련량을 정하며, 지도 능력이 실제 상승폭을 곱합니다. 코치는 물리에 직접 닿지 않고 선수 카드만 움직입니다. 선수 카드는 `derive_pitch_traits`로 구속·회전수·제구 σ가 됩니다.

코드: `bbsim/game/player.py`(선수 카드·자질·산출식), `training.py`(훈련 9축 카탈로그), `coaching.py`(코치·스태프·주간 루프). 테스트 `tests/test_coaching.py` 6건. 예제 `examples/run_coaching.py`.

## 1. 코치 능력치

| 능력치 | 뜻 | 작동 위치 |
|---|---|---|
| 진단 (diagnosis) | 선수의 진짜 약점을 얼마나 정확히 보는가 | 관측 노이즈 σ = 25 × (1 − 진단/100). 낮으면 엉뚱한 문제를 1순위로 꼽음 |
| 지도 (teaching) | 자기 분야 훈련의 효과 | 이득 배율 0.6 + 0.8 × 지도/100 (담당 코치 없으면 0.5) |
| 부하 관리 (load_mgmt) | 선수가 소화할 훈련량 판단 | 수용량 추정 오차 σ = 35% × (1 − 부하관리/100) + 과부하 편향 10% × (1 − 부하관리/100) |
| 소통 (communication) | 선수가 계획을 얼마나 따르는가 | 이행률 = 0.7 + 0.3 × (소통·선수 멘탈 평균) |
| 관찰 (observation) | 은닉 자질 추정 구간을 얼마나 빨리 좁히는가 | 주당 구간 폭 × (1 − 0.08 × 관찰/100) |
| 성향 (style) | 특정 능력치를 문제로 더 잘 꼽는 편향 | 지각된 격차 × (1 + 편향). 예: 구속 지상주의 감독은 하체 파워를 과대 진단 |

역할: 감독(head), 투수, 타격, 수비, 체력(conditioning), 멘탈, 의무(medical). 훈련 축마다 담당 역할이 있습니다(카탈로그 `domain`).

## 2. 주간 루프 (`Staff.run_week`)
1. **진단**: 분야 코치마다 자기 분야 능력치의 격차(상한 − 지각값) × 중요도 × 성향으로 순위. 감독 순위와 전문 코치 순위를 반반 합칩니다. 기록: 1순위 적중 여부, 순위 오차.
2. **계획**: 체력 코치(없으면 의무·감독)가 수용량을 추정하고, 상위 문제부터 훈련 세션을 채웁니다.
3. **실행**: 세션 이득 = 기본 1.6 × 가중치 × 지도 배율 × (0.5 + 자질 학습속도) × 이행률 × √여유도 × 피로 페널티. 훈련 안 한 능력치는 (1 − 유지력) × 0.25 감쇠. 피로 = 이전 × (1 − 회복) + 0.30 × (부하/수용량)². 피로 0.4 이상부터 이득이 줄어 1.0에서 30%만 남습니다. 과부하는 부상 위험을 올리고, 부상 시 통증·가동범위·반복성이 깎입니다.
4. **관찰**: 은닉 자질 구간이 관찰 능력만큼 좁아지고 참값 쪽으로 이동합니다.

## 3. 선수 카드 → 물리 (v0.5 산출식, `derive_pitch_traits`)
```
구속   = (84 + 16·속근) × (0.80 + 0.20·사슬) × 나이 배율 × 피로·컨디션,  사슬 = 0.5·하체 + 0.3·코어 + 0.2·어깨ROM
BU     = 20 + 8·(0.6·손목속도 + 0.4·손가락길이)                 (rpm/mph, 20~28)
f_force= min(1, 악력 / (35 + 0.8·(구속−85)))                     (포화)
회전수 = BU × 구속 × (0.85 + 0.15·그립숙련) × f_force
σ      = (0.30 − 0.14·반복성) × (1 + 0.5·피로) × (1.15 − 0.15·집중)   (m)
```

## 4. 검증 (tests/test_coaching.py)
- 진단 95 코치는 진단 10 코치보다 순위 오차가 작다.
- 부하 관리 95는 5보다 수용량 추정 오차가 작다.
- 같은 유망주 26주: 우수 스태프가 부실 스태프보다 능력치 합·구속이 높다.
- 부실 스태프가 과부하를 더 많이 낸다.
- 10주 관찰 후 자질 추정 구간 폭 < 0.6이고 참값을 포함한다.
- 능력치는 상한을 넘지 않는다.

## 5. 게임 층 연결 (예정)
- 감독 화면: 코치별 진단 보고서("이 선수의 1순위 문제는 반복성") — 진단 능력에 따라 틀릴 수 있음이 게임 재미.
- 스태프 영입: 능력치·성향·연봉. 성향 충돌(구속 지상주의 vs 제구 우선)이 계획 품질을 흔듦.
- 경기 중 감각 변수 s(PLAYER_ATTRIBUTES §8.3)와 실전 경험 이득은 시즌 루프에서 연결.
