# bbsim 물리 모델 (v0.1.0)

좌표계: 원점=홈플레이트 뒤 꼭짓점 지면, +x=포수 기준 오른쪽(1루측), +y=투수 방향, +z=위. SI 단위.

## 1. 공 비행 (`physics/ball.py`)

a = g + (ρA/2m)·|v|·( −C_D·v + C_L·(ω̂ × v) )

* S = rω/|v| (spin parameter), C_L = 1.5S (S<0.1), 0.09+0.6S (S≥0.1) — Nathan, Am. J. Phys. 76, 119 (2008)
* C_D = 0.35 상수 (AeroModel.cd 콜러블로 교체 가능)
* RK4, dt=1 ms(투구)/2 ms(타구). 회전 감쇠 무시.
* 검증(tests/test_physics.py): 94 mph 2300 rpm 포심의 무회전 대비 상승 0.25–0.60 m, 항력 감속 6–12 mph, 커브 낙차 0.20–0.60 m, 슬라이더 글러브측 이동 >5 cm.

## 2. 투구 생성 (`physics/pitch.py`)

* 구종 = (구속, 회전수, tilt, gyro 비율). tilt 0°=순수 백스핀, 90°=팔쪽 사이드스핀, 180°=톱스핀, 270°=글러브쪽. 좌완은 x 반전.
* 조준 솔버: 목표 지점을 향해 던지고 플레이트 앞면(y=0.432 m) 교차 오차만큼 조준점을 보정, 3회 반복 → 오차 <2 cm. 제구 오차는 호출자가 목표를 흔들어 넣습니다(투수 에이전트의 command_sigma).

## 3. 배트-공 충돌 (`physics/collision.py`)

3차원 강체 충격량 모델 + 마찰.

* 법선 n = cosθ·u + sinθ·w, sinθ = E/(r_ball+r_bat). E>0 = 배트가 공 아래(undercut).
* J_n = −(1+e)(v_rel·n)·m_red, 1/m_red = 1/m + 1/M_eff
* J_t = −min(|v_t|·m_red_t, μJ_n)·t̂, 1/m_red_t = 1/m + 1/M_eff + r²/I (구름 조건까지 마찰)
* ω' = ω + (−r n)×J_t / I → undercut이면 백스핀, topped면 톱스핀이 자동으로 나옵니다.
* e(v_n) = 0.50 − 0.001·(v_n − 26.8 m/s), [0.35, 0.60] 클립 (Nathan 2003 BBCOR 경향)
* M_eff(d) = 0.65 kg / (1 + (d/0.12 m)²) — 스위트스폿에서 멀어지면 급감
* 검증: 94 mph 포심 + 32 m/s 배트 정면 → EV 95–112 mph; E=+15 mm → LA>15°·백스핀; E=−25 mm → LA<0; |E|≥71 mm → 헛스윙.

## 4. 타이밍 오차 → 접촉 기하 (`engine/plate_appearance.py`)

* 타자 의도(t_contact, x_bat, z_bat, spray, attack angle, bat speed)에 신체 오차(σ_t=10 ms, σ_z=15 mm, σ_x=25 mm)를 더합니다.
* 공이 접촉면(y=플레이트 앞 +0.15 m)에 도달한 실제 순간의 배트 위치를 계산: 늦으면(Δt>0) 배트가 아직 덜 돌아 반대쪽·아래(attack angle 경로상), 이르면 당겨침·위. 각속도 30 rad/s → 10 ms당 17°.
* 이 기하가 E와 d를 만들고 3절 충돌 모델에 들어갑니다. 헛스윙·파울·뜬공·땅볼이 별도 확률표 없이 여기서 나옵니다.

## 5. 타자 인지 (`agents/perception.py`, `agents/batter.py`)

* 눈: 60 Hz, 각도 노이즈 σ=0.25°(거리 비례), 깊이축 노이즈 2배. commit 마감 = 접촉 0.20 s 전.
* 예측 = recognition·(2차 최소자승 외삽) + (1−recognition)·(등속 + 중력만). 변화구의 후반 변화가 그대로 기만 요소가 됩니다.

## 6. 결과 모델 (placeholder, `engine/outcome.py`)

펜스(양쪽 100 m, 중앙 122 m, 높이 2.6 m) 통과 시 HR, |spray|>45° 파울, 그 외 LA 구간별 안타 확률표. v0.2에서 야수 에이전트로 교체합니다.

## 8. v0.3 추가 (2026-09-05)
- **실밥 효과(seam-shifted wake)**: 그립별 계수 벡터 c_ssw(예: 싱커 [−0.03, −0.02], 체인지업 [−0.03, −0.03], 스플리터 [−0.01, −0.04], 좌완은 x 반전)를 (ρA/2m)|v|²·c_ssw 로 더합니다. 포심 마그누스 C_L≈0.2 대비 0.03이면 플레이트에서 약 4 in 추가 이동입니다. 경험 계수이며 Statcast 구종별 움직임으로 튜닝할 자리입니다.
- **회전 감쇠**: ω(t)=ω₀·exp(−t/12 s), 투구 한 번에 약 3% 감소.
- **환경**: ρ = p(고도)/(R·T) × 습도 보정, 바람은 공기 상대 속도로 항력·마그누스에 반영.
- **인체 사슬** (`physics/body.py`): 감사 반영. 팔 각도 = (외전−90°) + 측면 기울기(+5° 팔꿈치 항은 축 규칙에서), 팔 유효 길이 0.386h(팔꿈치 굴곡 20°), 골반 러버 앞 0.72·스트라이드, 뒷발 드래그 0.40·스트라이드, 마운드 경사 ground(y), 다리 도달 불가 시 골반 자동 하강, 구속 사슬 ±4% 클램프, 균형 배율(좌우 이탈·앞발 뒤 거리).
- **회전수 도출**: rpm = BU × 구속 × f_grip × f_force × 그립 계수. BU = 20 + 8·(0.6·손목속도 + 0.4·손가락길이), f_force = min(1, 악력/(35 + 0.8·(구속−85))).
- **회전축**: 그립 오프셋 + 손목 회내 + (90° − 팔 각도).
- **투구 간 변동**: 릴리스 σ(x 3~4 cm, z 2~3 cm), 축 σ 3~4°, 효율 σ 0.03, 회전 σ 3%. 타자는 릴리스 편차 6 cm 이상을 팁으로 읽습니다.
- **경기 중 피로**: 60구 초과분마다 구속 −0.04%, σ +0.4%, 회전 −0.03%.
- 검증: Statcast 2024 회귀(릴리스 높이 = 1.377 + 0.0099×팔 각도) ±15 cm, 익스텐션 0.95~1.15h, BU 20~28 (tests/test_body_intent.py).


## 9. 투구폼 프리셋과 자세→힘 효율 (v0.3.1, 2026-09-05)
- 프리셋 6종(`pitching_params.json: forms`): 오버핸드(외전 100·측면 42), 하이 쓰리쿼터(96·34), 쓰리쿼터(92·30, 기준), 로우 쓰리쿼터(90·22), 사이드암(86·10), 언더핸드(82·−22·전방 58).
- 사슬 효율 `chain_efficiency` = (1 + 스트라이드 항 + 전방 기울기 항) × (1 − 외전 손실) × (1 − 측면 손실) × (1 − 슬롯 손실) × (1 − 전방 과다 손실). 외전 손실은 95° 중심 가우시안(σ 18°, 최대 10%), 측면 −20~45° 밖 0.25%/°, 팔 각도 0° 아래 0.15%/°(최대 8%), 전방 50° 초과 0.2%/°.
- 코어 힘(0..1)이 잠재 효율을 실현합니다: realised = 1 − (1 − potential)(1 + 0.6(1 − core)) − 0.03(1 − core).
- 팔꿈치 부하 지수 = 1 + 0.004·|외전−95| + 0.003·max(0, 측면−30) (Matsuo 2006 경향, 상대 지표).
- 결과(키 1.85, 코어 1.0): 오버핸드 0.990, 하이 쓰리쿼터 0.998, 쓰리쿼터 0.997, 로우 쓰리쿼터 0.988, 사이드암 0.972, 언더핸드 0.917. 코어 0.5이면 각각 약 −2%.
- 타자 시점 지표 `perceived_at_plate`: 수직/수평 접근각(VAA/HAA), 체감 구속(익스텐션 1 ft당 +1.4 mph), 타자 눈에서 본 릴리스 고도각·방위각.
- 뷰어: 폼 프리셋 버튼, 코어 슬라이더, "기준 폼 고정" 체크 시 변형 전 뼈대·궤적을 점선으로 겹치고 릴리스·구속·σ·VAA·체감 구속 차이를 표시.
